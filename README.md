Hospital Operations - Exploratory Data Analysis (Tableau)
Project Overview
This repository contains an in-depth Exploratory Data Analysis (EDA) of a Hospital Management System using Tableau. The project focuses on transforming complex healthcare data into interactive visualizations to monitor hospital performance, patient trends, and resource allocation.

Key Insights & Features
Operational KPIs: Monitoring of critical metrics such as patient admission rates, average stay duration, and department efficiency.

Patient Demographics: Analysis of patient inflow based on age, gender, and insurance status to optimize hospital services.

Trend Analysis: Identification of peak hours and seasonal trends in emergency and outpatient departments.

Dynamic Interactivity: Implementation of advanced filters, parameters, and actions to allow users to drill down into specific datasets.

Technical Skills Used
Data Visualization: Created professional dashboards using Tableau Desktop with a focus on UX/UI for data reporting.

Data Preparation: Performed data cleaning and transformation using SQL and Tableau Prep.

Analytical Techniques: Utilized Calculated Fields, Table Calculations, and Data Blending to derive complex insights.

Statistical Analysis: Applied trend lines and distribution charts to understand data patterns.
